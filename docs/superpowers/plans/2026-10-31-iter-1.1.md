# 迭代 1.1 实现计划

> **For agentic workers:** 本计划由主会话内联执行（用户睡前授权自主落地，不派子代理改同一批前端文件）。步骤用 `- [x]` 跟踪；每步 TDD：先写失败测试→跑红→最小实现→跑绿→提交。

**Goal:** 让每台 FRPS 服务器可单独指定 frpc 版本（缺省跟随默认、缺失先默认后补下载并自动切换），代理远程端口支持一键同本地端口与占用检测（保存时自动校验、占用硬阻断），并在 WebUI/README 增加开源仓库入口与 Star 引导。

**Architecture:** 后端在 `instances` 表加 `frpc_version` 列（空=跟随默认），`Manager` 按实例解析二进制并记录实际生效版本；启动完成后 reconcile 补下载指定版本，下载完成自动重启切换。新增 `POST /api/proxies/check-port`：本机跨服务器查重 + TCP 探测三态（udp 仅查重）。前端在服务器表单/列表/仪表盘/代理 Tab 显示版本，代理弹窗远程端口行加两个按钮并在保存前校验；顶栏/登录页/设置/README 加仓库入口。

**Tech Stack:** Go 1.23（stdlib + modernc sqlite）、Vue 3 + Element Plus + Pinia、shields.io 徽章。

**规格:** `docs/superpowers/specs/2026-10-31-iter-1.1-design.md`（唯一需求来源；issue #6）
